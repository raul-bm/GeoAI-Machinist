# GeoAI-Machinist
A game to teach GeoAI. More specifically, the application of Convolutional Neural Networks for Land Use and Land Cover Classification

# Firebase Firestore usage
To be able to store the different data on Firebase Firestore, it needs to be created a json file name "env.json" on "Assets/Resources". This JSON has to be like this:

{
"firebaseApiKey" : "API-KEY",
"firebaseProjectId": "PROJECT-ID"
}
